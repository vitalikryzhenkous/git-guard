# git-guard — правила для агента
- Язык: Python 3 stdlib only. Внешний бинарь только gitleaks. Хуки — bash-обёртки ≤5 строк.
- Тесты: pytest, каждый блок — тест на срабатывание (✗) и на чистый коммит; репо для тестов создаются во временных папках.
- Никогда не печатать найденные термины и секреты: только репо, коммит, файл, тип.
- Не читать содержимое terms.txt в вывод и не коммитить его.
- Не переписывать историю, не пушить в другие репо, не менять core.hooksPath без явной команды.
- Изменение правил блокировки = отдельный PR с примером ложного срабатывания или пропуска.
- DoD и прогресс — в state.md; стоп после каждого шага.
- Общие git-правила (явный add, diff --cached --stat, без --no-verify и force-push) — в ~/.claude/CLAUDE.md, здесь не дублировать.
